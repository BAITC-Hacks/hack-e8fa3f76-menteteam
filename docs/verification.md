# Проверка реализации — 23 сентября 2026

## Окружение

- Python 3.12.14; зависимости установлены из `uv.lock`.
- NVIDIA Tesla T4, 15 360 MiB доступной VRAM, драйвер 595.91.07.
- PyTorch 2.8.0+cu126, CUDA runtime 12.6, Transformers 5.17.0.
- Gemma: `google/gemma-4-E2B-it`, FP16; Whisper: `small`, `int8_float16`.
- Community-1 работает локально; HF-аутентификация использована для скачивания весов.

Полный прогон дал 26 сегментов, 4 speaker ID, 8 поручений и 6 решений; поле предупреждений результата пусто. Артефакт `data/cache/gpu-diarization.json` хранится только локально и исключён из git вместе с весами и `.env`. Один замер памяти во время первоначального запуска Gemma показал 10 227 MiB; это не измерение пикового потребления.

При импорте pyannote среда сообщала об отсутствии системных FFmpeg-библиотек для TorchCodec. Наш адаптер передаёт заранее декодированный PyAV waveform, и полный прогон прошёл. Для обычной установки и контейнера FFmpeg предусмотрен инструкцией/Dockerfile.

## Что подтверждено тестами

Проверяются grounding цитат и таймкодов, RU/KZ даты, границы имён/слов, разделение говорящего и ответственного, смена спикера на уровне слов, JSON-валидация, ключи кэша с локальными путями, отдельные совещания с одинаковыми названиями, сохранение правок через Streamlit, контроль подтверждения и повторов уведомлений, отмена отправки после изменения адресата/одобрения, HTTP Host/Origin/token/consent, Unicode-экспорт, обезличивание и ICS.

Независимое ревью выявило ошибки с подстроками имён/сроков, цитатами нескольких спикеров и устаревшими адресатами в рассылке. Добавлены воспроизводящие регрессии и исправления. Передача HF token в Gemma также исправлена.

## Границы подтверждения

Этот прогон подтверждает работоспособность на указанной записи и оборудовании, а не точность распознавания на любых RU/KZ/смешанных записях. WER, точность диаризации и полнота поручений не измерены относительно ручного эталона. Нет независимой приёмки реальных Teams/Zoom/Meet аккаунтов, SMTP-доставки или Docker-образа. Платформенный вход остаётся с участием оператора. Реальные письма при разработке не отправлялись.
