# Alem Minutes

Локальный прототип автопротоколирования совещаний. Faster-Whisper выполняет транскрибацию, pyannote Community-1 — диаризацию, Gemma 4 E2B через llama.cpp извлекает поручения и саммари. Фактическое аудио и транскрипт не передаются во внешние inference API.

## Запуск в Arch Linux / WSL

Установите `uv`, `ffmpeg` и свежую сборку `llama.cpp` с `llama-server` (Gemma 4 требует свежей версии llama.cpp). Официальная инструкция и готовая сборка: [llama.cpp](https://github.com/ggml-org/llama.cpp); model card публикует интеграцию через llama.cpp.

```bash
sudo pacman -S uv ffmpeg ttf-dejavu
cd /mnt/c/Users/admin/Documents/hackalem
./run-local.sh
```

Отдельно запустите локальный LLM сервер; GGUF автоматически скачается в llama.cpp cache:

```bash
llama-server -hf unsloth/gemma-4-E2B-it-GGUF:Q4_K_M --host 127.0.0.1 --port 8080 -ngl 99 -c 8192
```

Это GGUF Q4_K_M размером около 3.11 GB. Для CPU уберите `-ngl 99`; для арендуемого NVIDIA сервера используйте CUDA-сборку llama.cpp и оставьте `-ngl 99`, чтобы выгрузить слои Gemma в видеопамять. Модельный id в приложении по умолчанию `gemma-4-E2B-it-Q4_K_M`, адрес API `http://127.0.0.1:8080/v1`. Модель и endpoint настраиваются через `.env`.

Откройте `http://localhost:8501`. В первый раз Whisper скачает выбранные веса в `data/models/`. По умолчанию выбран `small`; если сервер позволяет, переключите на `medium` или `large-v3-turbo`.

## Диаризация

Чтобы установить локальные зависимости pyannote, runner выполняет `uv sync --extra diarization`. Для весов `pyannote/speaker-diarization-community-1` примите условия модели на Hugging Face и задайте read token в `.env` как `HF_TOKEN`. Token нужен только для скачивания/доступа к весам; само аудио обрабатывается локально. Без token распознавание и LLM анализ доступны, но спикеры останутся неопределёнными, а приложение покажет это как предупреждение.

## Демонстрация

1. Откройте `http://localhost:8501`.
2. Оставьте одну или обе тестовые записи выбранными.
3. Нажмите **Распознать и составить протокол**.
4. Просмотрите транскрипт, решения, поручения, цитаты и вопросы по неизвестным владельцам/срокам.
5. Скачайте протокол в DOCX или PDF.

Поручение отображается только когда evidence-цитата найдена в распознанной речи. Время воспроизведения берётся из таймкода сегмента Whisper, а не из ответа LLM. Предложение не считается поручением.

## Приватность и ограничения

- llama.cpp server принимается только на `localhost`/loopback; адреса внешних inference API блокируются. Сам сервер нужно запускать отдельной командой.
- Аудио и текст обрабатываются локальными моделями. Внешняя сеть нужна только для первичной загрузки весов.
- `data/cache`, `data/models`, `data/uploads` и `.env` исключены из git.
- Без HF token диаризация недоступна. Teams/Zoom/Meet integration и автоматические напоминания пока не реализованы.
- Перед публичным демо обезличьте реальные записи.
